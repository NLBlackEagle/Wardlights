# Wardlights

A small Minecraft 1.12.2 (Forge) mod that adds equipable lantern baubles which keep
darkness entities at bay.

Lanterns can be worn as a bauble, held in the right hand, or slotted in a tool belt.
Planned variants:

- **Regular Lantern** – a light source that stops darkness mobs from targeting you.
- **Pixie Infused** – a larger light radius plus a mining-speed boost.
- **Vapula Infused** – prevents Vapula & Geonach from spawning while you tear down their home.
- **Pale Infused** – regular darkness entities fear you instead of hunting you.

Built on [FermiumBooter](https://www.curseforge.com/minecraft/mc-mods/fermiumbooter)
for mixin loading. JEI is an optional integration.
